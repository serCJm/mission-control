# Mission Control promotional video

`mission-control-promo.mp4` is the delivery master: a 1920×1080 H.264 promotional walkthrough with an original ambient music bed and a default English closed-caption track.

`captions/mission-control-promo.srt` is included as a sidecar for platforms that ingest captions separately. `mission-control-promo-master.mp4` contains the same edit and music without the embedded caption track.

The walkthrough covers quick capture, Inbox processing, area and project organization, board/list task views, project notes, routines, recurring area blocks, block execution, and Weekly Review. The interactions were staged without submitting changes to the development workspace.
